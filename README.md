# Arbor Latina — «Латинское дерево»

200 крылатых латинских выражений с мнемониками, историей, словами-потомками и транскрипцией.
Выходит в двух видах из одних и тех же данных:

- **веб-книга** — один файл `dist/index.html` (работает офлайн: шрифты, рисунки и скрипты внутри):
  анимация растущего дерева, поиск, фильтры по уровню и областям жизни, светлая и тёмная тема;
- **PDF для печати** — `dist/arbor-latina.pdf`, формат A5, 212 страниц, одна фраза на странице,
  оглавление и алфавитный указатель с номерами страниц.

Список фраз построен по статье «[Список крылатых латинских выражений](https://ru.wikipedia.org/wiki/Список_крылатых_латинских_выражений)»
(русская Википедия, CC BY-SA 4.0). Тексты, мнемоники и рисунки написаны заново.

## Устройство книги

Четыре уровня по 50 фраз; названия взяты из дерева, и на страницах уровней оно «дорастает»
от корней до кроны:

| Уровень | Название | Что внутри |
|---|---|---|
| I | *Radices* — корни | слышал каждый |
| II | *Truncus* — ствол | знакомо, но вспоминается со второй попытки |
| III | *Rami* — ветви | для тех, кто читает больше, чем нужно |
| IV | *Frondes* — крона | блеснуть эрудицией |

Карточка фразы: латынь и перевод; две транскрипции (**по-русски** — как принято в отечественной школе
латыни, и **для американского уха** — английская запись классического произношения); мнемоника одного из
четырёх типов (**образ**, **созвучие**, **сценка**, **смысл**); у ~60 фраз — штриховая иллюстрация;
раскрывающийся блок «Разобрать глубже»: история, слова и потомки, пример сегодня, грамматика в одну строку,
«как цитируют неверно», связанные фразы. Тонкой строкой над названием — области жизни.

Полный список: [`docs/phrases.md`](docs/phrases.md).

## Как собрать

Нужен Node.js 20+ (проверено на 22) и для PDF — Chromium (Playwright) и Python 3 с `pymupdf`.

```bash
npm install                 # playwright-core
node build.mjs --strict     # проверка данных + сборка dist/index.html
node scripts/pdf.mjs        # dist/arbor-latina.pdf (два прохода: сначала считаются страницы)
node scripts/make-index.mjs # docs/phrases.md
node scripts/lint-content.mjs   # линтер содержания
node scripts/test-web.mjs   # функциональные проверки веб-версии
```

`pip install pymupdf` нужен только для подсчёта страниц в PDF. Пути к Chromium в `scripts/*.mjs`
рассчитаны на `/opt/pw-browsers`; при необходимости поправьте `executablePath`.

## Как править содержание

Данные лежат в `src/data/level1.js … level4.js`; схема карточки описана в начале `level1.js`.
Ударение в русской транскрипции ставится апострофом после гласной (`а'леа я'кта эст`),
в английской записи ударный слог пишется ЗАГЛАВНЫМИ.

`build.mjs --strict` проверяет: уникальность id, наличие всех полей, допустимые области жизни, символы
в транскрипциях (кириллица без латиницы!), существование иллюстраций и связанных фраз,
ровно 50 фраз в каждом уровне. После правки текста заново запустите `scripts/pdf.mjs`:
он сообщит, если какая-то карточка перестала помещаться на одну страницу.

## Иллюстрации и дерево

- `src/tree.mjs` — процедурное дерево (кроны, корни, листья) из сотен штрихов; каждая линия «рисуется»
  анимацией `stroke-dashoffset`. Стадии `stage 1–4` дают дерево от корней до кроны для страниц уровней.
- `src/illustrations.mjs` — штриховые SVG-рисунки; у каждого один красный акцент. Контактный лист:
  `node scripts/illpreview.mjs [ключи…]`.

## Допущения

- «Для американского уха» понято как английская запись *классического* произношения
  («WAY-nee, WEE-dee, WEE-kee»); русская транскрипция следует традиции русской школы («вени, види, вици»).
  Если нужна другая система (например, церковная), это одно поле `en` / `tr` в данных.
- Фразы, которых нет в русской Википедии в нужной форме, приведены в классической форме источника
  (например, *Ne sutor supra crepidam* у Плиния вместо «Nec sutor ultra crepidam»); вариант оговорён в карточке.
